# TweakOS

Клиентский мод Minecraft **1.12.2** (Forge) — гардероб косметики и override resource pack.

**Создатель:** AyanamiKaede

## Возможности
- Плашка Wardrobe слева от персонажа в инвентаре
- Категории: Шапки / Косметика на руку
- Превью-рендеры (`preview.png`) + цветовые варианты
- Клон серверного RP → `work_pack`, правки моделей только в нём
- Приоритет паков (серверный можно двигать)
- Кнопка **+** — добавить свою модель

См. `docs/CATALOG.md`.

## Сборка
```bash
./gradlew build
```
JAR: `build/libs/TweakOS-1.4.0.jar`
