# TweakOS

Клиентский мод Minecraft **1.12.2** (Forge) для косметики и override resource pack на RP-серверах.

**Создатель:** AyanamiKaede

## Возможности
- Меню Wardrobe (кнопка в инвентаре рядом с персонажем)
- Каталог моделей + Apply в локальный override
- Override поверх серверного RP
- Профили по IP, избранное, стек паков
- Автообновление base/catalog через GitHub (`update/version.json`)

## Сборка
```bash
./gradlew build
```
JAR: `build/libs/TweakOS-1.3.1.jar`
